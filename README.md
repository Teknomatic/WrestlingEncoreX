# Wrestling Encore 2.0.0

Wrestling Encore returns. First released twenty years ago, this updated edition brings the classic wrestling career simulation to modern PCs while preserving the game and its distinctive wrestling world.

Version 2.0 is the first major modernized release since version 1.6. It marks a new chapter for the original game, not a sequel.

## What's new in 2.0.0

- **BlitzX3D engine migration** brings the game onto a modernized engine foundation.
- **Windows 10 and Windows 11 support** lets the game run on today's Windows PCs.
- **HD display modes** and updated interface scaling make menus and in-game screens more comfortable on modern displays (1080p, 1440p, and 4K).
- **Gamepad support** has been expanded, including configurable directional controls. (Up to 16 buttons are supported)
- **Updated visuals** include higher-resolution portraits and interface assets.
- **Career and interface refinements** improve report layouts, stat-change highlighter rescaled, and career-calendar scrolling.

Wrestling Encore 2.0.0 is a revival of the original experience: build a wrestler's career, navigate the wrestling business, and make your way through a changing world of promotions and competitors.
